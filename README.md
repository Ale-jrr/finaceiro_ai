# FinMind Clone

Clone funcional da página principal baseado nas imagens enviadas.

## Como abrir

Abra `index.html` no navegador.

## Funcionalidades

- Sidebar com navegação
- Cards de métricas: saldo, entradas, saídas e eficiência
- Bloco de evolução: XP, nível, streak, conquistas e quest
- AI Insight mockado
- Gráfico de evolução financeira em canvas
- Formulário Nova Transação (entrada/saída)
- Histórico com exclusão
- Persistência em localStorage
